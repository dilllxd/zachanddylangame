# data
Resource definitions (.gd with class_name) and the .tres files made from them. Pure data, no behaviour.
- fish/ FishData: name, sprite, price, income_per_sec, hunger_rate, growth_stages
- food/ FoodData: name, cost, nutrition
- upgrades/ UpgradeData: name, cost, description
To add one: right click the folder > New Resource > pick the type, fill it in the inspector.
